# agent-sdk-kotlin

Agent typed client SDK for Kotlin/JVM (`agent.v1.AgentService` via
Connect). Generated by buf from `agent/v1/agent.proto`; this package adds
`ProtocolClient` (OkHttp, Connect) + bearer auth. Talks only to the agent.

```kotlin
val client = AgentClient(baseUrl = "https://agent.example.com", token = "")
val sessions = client.listSessions() // suspend
```

```kotlin
repositories { mavenCentral() }
dependencies { implementation("com.agent:agent-sdk-kotlin:0.1.0") }
```
